# AGENTS.md - mediamukhtar.no (Sajid Mukhtar)

Dette dokumentet definerer retningslinjene, teknologistacken og designprinsippene for dette prosjektet. Alle fremtidige endringer og kodeutvidelser skal følge disse instruksjonene.

## 1. Prosjektformål
* Prosjektet er en personlig og profesjonell landingsside for mediamukhtar.no (Sajid Mukhtars foto- og medieportefølje).
* Målet er å fremheve bildene på en estetisk, moderne og innbydende måte.

## 2. Teknologistack
* **HTML5:** Semantisk, ren og tilgjengelig struktur.
* **Tailwind CSS:** Brukes for all styling (rask og responsiv layout via Tailwind Play CDN eller utility-klasser).
* **JavaScript (ved behov):** Lettvekts og ren vanilla JS for bildeforhåndsvisning (lightbox), mobilmeny eller filtrering av kategorier.

## 3. Designprinsipper
* **Mørk fargepalett:** Dype, elegante mørke toner (som `#0b0f17`, `#111827`, `#18181b` og nøytrale gråtoner) for å la fotografiene og fargene i bildene stå i sentrum uten distraksjoner.
* **Minimalistisk og ryddig:** Rikelig med luft (whitespace/negative space), diskré typografi, subtile overganger og ingen unødvendig visuell støy.
* **Bilde-først:** Bildene er heltene på siden. Gallerier skal være responsive og gi bildene god oppløsning og riktig sideforhold (aspect ratio).
* **Typografi:** Moderne sans-serif (f.eks. Inter / system-ui) med behagelige kontraster mot den mørke bakgrunnen.
